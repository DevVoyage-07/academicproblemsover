# 🌼 Daisy AI – Universal Academic Solver

**Solve Any Problem Instantly. Learn Smarter with Daisy AI!**

Daisy AI is a multi-subject academic problem-solving web application designed to help students understand concepts, solve academic questions, and organize their study materials in one place. It supports multiple educational domains, photo-based question input, document storage, and collaborative learning.

🔗 **Live Demo:** https://academicproblemsover.netlify.app

## ✨ Features

* 📚 **Multi-Subject Learning:** Supports Mathematics, Physics, Chemistry, Biology, Social Studies, General Knowledge, Computer Science, and Engineering.
* 📸 **Photo-Based Question Input:** Scan or upload pictures of academic problems for assistance.
* 💡 **Step-by-Step Problem Solving:** Get help understanding questions and working through solutions.
* 📐 **Mathematical Symbols:** Quickly insert mathematical symbols such as √, ∫, π, Σ, θ, ∞, and more.
* 📁 **Dual Document Storage:** Organize previously solved answers and newly submitted questions.
* 📝 **Answer History:** Maintain an archive of solved academic problems and explanatory notes.
* 📌 **Question Queue:** Keep track of newly submitted questions and doubts.
* 👥 **Collaborative Study Rooms:** Study and discuss problems with friends.
* 🎓 **Student-Friendly Interface:** Designed to make academic problem solving more accessible and organized.

## 🚀 Getting Started

### Use the Live Application

1. Open [Daisy AI](https://academicproblemsover.netlify.app).
2. Select the relevant academic subject.
3. Enter your question or use the photo upload option.
4. Use Daisy AI to seek help with your problem.
5. Organize questions and solved answers using the available file storage features.
6. Explore study rooms for collaborative learning.
